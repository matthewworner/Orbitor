## GitHub Release v1.0.0

### Tag
`v1.0.0`

### Title
Nature's Calm vs. Humanity's Noise - A macOS Screensaver

### Notes
A macOS screensaver contrasting cosmic serenity with the chaotic swarm of 23,000+ satellites orbiting Earth.

**Features:**
- 🪐 Solar system with 8K NASA textures (Sun + 8 planets)
- 🛰️ 23,000+ satellites rendered in real-time
- 🔭 NASA 3D models (Hubble, TESS, TDRS, Juno)
- ✨ Data-driven visualization (ISS, Starlink, debris each look different)
- 🌍 Motion trails showing orbital paths
- ⚡ Hybrid SceneKit + Metal rendering at 60fps

**Installation:**
1. Download `NatureVsNoise-v1.0.0.zip`
2. Unzip and double-click `NatureVsNoise.saver`
3. Or copy to `~/Library/Screen Savers/`
4. Select in System Settings → Screen Saver

**Requirements:** macOS 13.0+

## Hacker News

### Title
Show HN: A macOS screensaver visualizing 23,000+ satellites orbiting Earth

### Body
Hi HN! I built a screensaver that shows the real satellite population around Earth.

The idea came from learning there are over 23,000 tracked objects in orbit - satellites, debris, spent rocket bodies. I wanted to visualize this "space traffic" in a way that's both beautiful and sobering.

What you see:
- Real orbital data from CelesTrak (updated TLE files)
- SGP4 propagation for accurate positions
- ISS, Starlink, debris all render differently
- 8K planet textures from NASA
- Metal + SceneKit hybrid rendering for 5000+ visible objects at 60fps

The contrast between the serene solar system backdrop and the swarm of human-made objects is the whole point - nature's calm vs humanity's noise.

Built with Swift/SceneKit/Metal. Open source on GitHub.

Happy to answer questions about orbital mechanics, the Metal rendering pipeline, or why satellite classification matters for visualization.
